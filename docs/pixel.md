ทุกคนที่ใช้ Claude Code ต้องมี Extension นี้... เปลี่ยนหน้าจอ Terminal น่าเบื่อ ให้กลายเป็นออฟฟิศส่วนตัว! 🔥
.
ใครที่เริ่มใช้ AI Agent เขียนโค้ดคงเข้าใจดี... นั่งดูตัวหนังสือวิ่งไปวิ่งมาบน Terminal ดำๆ มันทั้งเครียด ทั้งล้าสายตา
• ตอนนี้ AI กำลังคิด หรือกำลังเขียนโค้ด?
• หรือมันกำลังรอให้เรากด Approve อยู่?
• แล้วถ้าเราเปิด AI หลายๆ ตัวพร้อมกันล่ะ? งงไปหมด!
.
วันนี้ผมไปเจอของดีมาครับ! "Pixel Agents" (GitHub 5.5k ดาว) เป็น VS Code Extension ฟรี ที่มาเปลี่ยนการทำงานกับ Claude Code ให้เหมือนเล่นเกม The Sims! ทุก Agent จะกลายเป็นตัวละคร Pixel Art เดินไปเดินมาในออฟฟิศที่คุณออกแบบเองได้!
.
ขั้นตอนที่ทำจริง (ทุกคนทำตามได้ง่ายๆ)
.
ขั้นตอนที่ 1 — ติดตั้ง Extension (ง่ายกว่านี้ไม่มีแล้ว)
เปิด VS Code ของคุณขึ้นมา ไปที่เมนู Extensions ค้นหาคำว่า "Pixel Agents" แล้วกด Install ได้เลยครับ ฟรี 100% (หรือโหลดจาก VS Code Marketplace ก็ได้)
(หมายเหตุ: ต้องติดตั้ง Claude Code CLI ไว้ในเครื่องก่อนนะครับ)
.
ขั้นตอนที่ 2 — เปิดออฟฟิศ สร้างพนักงาน AI
เปิดพาเนล Pixel Agents ขึ้นมา (อยู่ด้านล่างข้างๆ Terminal) แล้วกดปุ่ม "+ Agent" เพื่อสร้าง Claude Code terminal ใหม่
เทคนิคคือ: ทันทีที่คุณกด จะมีตัวละครโผล่ขึ้นมาในออฟฟิศ! 1 Agent = 1 ตัวละคร
.
ขั้นตอนที่ 3 — สั่งงานแล้วนั่งดูเพลินๆ
ลองพิมพ์สั่งงาน Claude Code ตามปกติ แล้วดูความมหัศจรรย์ครับ!
• ถ้า AI กำลังเขียนโค้ด ตัวละครจะทำท่าพิมพ์คีย์บอร์ด
• ถ้า AI กำลังค้นหาไฟล์ ตัวละครจะทำท่าอ่านหนังสือ
• ถ้า AI รอเรากด Approve จะมี Speech bubble เด้งขึ้นมาเตือน!
.
ขั้นตอนที่ 4 — (Optional) ตกแต่งออฟฟิศสไตล์ CEO
คลิกปุ่ม "Layout" เพื่อเปิด Editor คุณสามารถเปลี่ยนสีพื้น สร้างกำแพง จัดวางโต๊ะ เก้าอี้ ต้นไม้ หรือตู้กดน้ำได้ตามใจชอบเลยครับ เหมือนสร้าง Digital Office ของตัวเองจริงๆ
.
Pixel Agents คือเครื่องมือที่ทำให้การทำงานกับ AI ไม่ใช่เรื่องเครียดอีกต่อไป แต่มันคือการที่เราได้เป็น CEO คุมทีม AI จริงๆ ใครใช้ Claude Code อยู่ ห้ามพลาดเด็ดขาดครับ!
